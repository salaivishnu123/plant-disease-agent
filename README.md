🌿 AI Plant Disease Detection

This project is an AI-based plant disease detection system built using Deep Learning, Flask, and Explainable AI techniques.
The system allows users to upload a plant leaf image and predicts the disease using a trained CNN model. It also generates a Grad-CAM visualization to show which part of the leaf the model focused on while predicting.
Along with prediction, the project uses Groq AI API to provide disease explanation, causes, treatment methods, and prevention tips in simple farmer-friendly language.

---

# Features

- Plant disease prediction using CNN
- Grad-CAM explainability visualization
- AI-generated disease analysis
- Dashboard for prediction analytics
- SQLite database integration
- Flask backend API
